# Bauhinia Resort & Spa — 2027

A future-facing Phu Quoc resort landing page designed around a warm wood / burnt-orange visual identity and an editorial hospitality experience.

## Concept
- Immersive hero with oversized typography
- Warm wood + burnt orange palette
- Editorial room showcase
- Daily ritual timeline
- Phu Quoc / 2027 positioning without implying official APEC affiliation
- Mobile navigation and responsive layouts
- Lightweight Next.js + Tailwind + Framer Motion-ready stack

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Source references
The content direction uses publicly available information about Bauhinia Resort & Spa: warm-coloured woody rooms, outdoor pool, spa, restaurant, Long Beach proximity and contact details. The visual design is original.
